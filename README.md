# 🧑‍💼 Job Portal Web Application

A full-stack job listing web application built with **React (Vite + Tailwind CSS)** for the frontend, **Spring Boot** for the backend, and **MongoDB** as the database.

---

## 🚀 Features

- Add new job listings
- Search job listings by keyword
- View all posted jobs
- Modern, responsive UI with Tailwind CSS
- RESTful API built with Spring Boot
- MongoDB integration for persistent data storage

---

## 🛠 Tech Stack

### Frontend
- React (with Vite)
- Tailwind CSS
- Axios

### Backend
- Spring Boot
- Java 17+
- Spring Data MongoDB
- Jakarta Validation (Bean Validation)

### Database
- MongoDB (Atlas)
